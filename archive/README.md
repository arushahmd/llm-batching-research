# Archive

The active thesis-v2 repository keeps historical research separate from the
current standardized Group 1 protocol.

Earlier thesis experiments used materially different settings and are preserved
through the repository's legacy branch and tag rather than mixed into the
active result tables.

This directory is reserved for lightweight notes or references to superseded
artifacts when keeping them in the active tree is useful.

Large historical outputs, checkpoints, caches, and duplicate notebooks should
not be copied here.
